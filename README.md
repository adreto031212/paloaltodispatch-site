# paloaltodispatch.com

Static landing site for the Palo Alto Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py paloalto` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `paloalto-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
